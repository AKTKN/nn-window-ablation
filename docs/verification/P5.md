# P5 verification

## Claim and scope

C5 covers G/F/S inference composition and conditional whole-trajectory
statistics for a fixed held-out dataset and terminal checkpoint. C1 supplies
the joint physical labels, C2 the allowed observations, C3 the shared model,
and C4 the dataset and checkpoint integrity contracts. The local fixtures
exercise the full distance-5 architecture with one training update.

## Inference and artifacts

`nnwa evaluate evaluation=paired` loads one terminal model and applies G,
F, and S to the same bounded batches of complete trajectories. G predicts the
global label from full context. F and S predict the same 12 core labels using
full context and deployment windows, respectively. A zero logit is an
inclusive positive decision, equivalent to sigmoid probability at least 0.5.
The composed prediction is the XOR of the hard core decisions. The evaluator
checks a canonical hash of all parameter and buffer names, shapes, dtypes,
and bytes around inference. It supplies cropped detector data and public query
metadata to the model in evaluation and inference modes.

The separate G, F, and S presets remain available. Prediction schema 1 binds
against the P4 dataset ID and manifest digest, split, bit order, and label and
feature schemas. Each prediction shard aligns its `shot_ids.npy` with the
verified dataset shard. The pair of dataset ID and numeric row key resolves to
the P4 canonical trajectory identity. The prediction shard contains packed
decisions, finite query logits for neural modes, final F/S XOR bits, and a
manifest inventory of shapes, valid bits, and byte hashes. Analysis checks
coverage, row order, threshold decisions, final composition, and query release
metadata before accepting results. Staged publication uses P4's filesystem
assumptions. [P4 filesystem contract](P4.md#interfaces-and-schemas)

Each condition records inference mode separately from checkpoint digest,
training regime, seed, replicate, optional parent, and model-state hash. The
saved checkpoint training context determines the labels S, S+, W, or D for
window inference. Adapted companions use identities such as
`G@fixed_window` and `F@fixed_window`. Primary G/F/S inputs must share both
checkpoint and model-state hashes. An optional MWPM reference decodes the same
raw detector rows with the original decomposed, global-only DEM and records
its hash, dimensions, PyMatching version, and default options. [PyMatching API](https://pymatching.readthedocs.io/en/stable/api.html)

## Statistical computation

`nnwa analyze` reads sealed predictions and the bound dataset. It writes a
JSON report and two CSV tables. Analysis reports per-condition failure counts,
LER and 95% Wilson intervals, and mean query cross entropy. Core diagnostics
include per-core disagreements, adjacent joint counts and correlations, the
number of disagreements per shot, the odd-disagreement rate, and first,
interior, and last positions. The query metadata retain physical endpoint
flags. Model cross entropy uses the original global label for G and the
individual core labels for F and S. [SciPy binomial intervals](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html)

Each contrast reports all four contingency counts, the signed LER difference,
discordance rate, and interval limits. The primary decomposition is checked
in integer count numerators before division by their common shot count.
For discordances above the supplied cutoff, the implementation uses a
two-sided percentile interval from four-category multinomial draws. This has
the distribution of resampling complete paired trajectories for these
statistics. It records the inclusive sparse cutoff, NumPy PCG64 seed,
replicate count, linear quantiles, contrast order, and software environment.
For discordances at or below the cutoff, the interval is
$[L_{10}-U_{01},U_{10}-L_{01}]$ with two 97.5% Clopper–Pearson intervals using
the full shot count. With zero discordances, the limits are
$\pm(1-0.0125^{1/N})$. [Protocol](../02_ablation_protocol.md#72-paired-comparisons) ·
[SciPy paired bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)

The optional ratio uses the second condition's LER as denominator and the
same paired draw table. A denominator below the configured failure minimum
or any zero-denominator replicate yields unresolved ratio uncertainty.
An analysis invocation covers one training seed and replicate. The main
discordance cutoff, bootstrap seed and replicate count, ratio minimum, and
between-seed aggregation remain to be fixed from the pilot.

## Executed checks

| Test file | Independent expectation and observed behavior |
|---|---|
| `test_p5_prediction_composition.py` | Hand-written nonzero targets and zero through three disagreements verify parity and cancellation. Shape, binary-bit, and inconsistent-label controls are rejected. |
| `test_p5_paired_statistics.py` | Literal counts verify both signs of a $1/6$ difference, full agreement and disagreement, equal-marginal unequal pairings, and decomposition. Missing, duplicate, substituted, and permuted identities are rejected. The ratio checks cover resolved bounds, inadequate denominators, and undefined bootstrap draws. |
| `test_p5_confidence_intervals.py` | The Wilson score calculation reproduces the 0/10 and 10/10 limits and an interior case. An independent finite binomial-tail inversion checks exact marginal limits and the sparse combination. The zero-discordance interval remains nondegenerate. |
| `test_p5_bootstrap_units.py` | Exhaustive resampling of five trajectories and an independent multinomial probability calculation agree. Fixed-seed draws repeat. Independent resampling of the windows of a cancelling fixture incorrectly produces a 0.5 odd rate. |
| `test_p5_condition_provenance.py` | Four recorded checkpoint regimes map to S/S+/W/D. Incompatible label and feature schemas, physical recipes, caller inference policies, checkpoint identities, training replicates, and deployment queries are rejected. |
| `test_p5_d5_paired_evaluation.py` | Real P1 sampling, P4 generation and one-update checkpoint, P2 cropping, P3 256-wide four-layer GRU, all 12 core predictions, persisted arrays, and paired analysis ran on three distance-5, 60-round shots at $p=0.003$. Per-shot parity, failure counts, model identity, and signed contrasts were checked against stored rows. A changed caller training preset leaves the saved condition unchanged. A forged endpoint and resealed ID permutation fail validation. |
| `test_p5_matching_baseline.py` | Actual original DEM and joint detector rows pass through PyMatching. Batch predictions agree with rowwise matching, the DEM identity is recorded, and a second observable is rejected. |

The integrated model uses $d=5$ with five-round buffers, and checks release
at $T^{-}$ for core 10 and $T^{+}$ for core 11 using zero-based IDs. Inverting
destructive-readout detector bits preserves the penultimate crop and logits
exactly. Reordered and separately batched float32 outputs use absolute
tolerance $2\times10^{-6}$ and relative tolerance $10^{-5}$ for reductions and
recurrent arithmetic. Model hashes, stored bits, counts, and identities are
checked exactly. The statistics use independent arithmetic and finite
enumeration, with approximate comparisons for floating-point intervals.

## Environment and commands

The P5 source was based on `e8e54e96b3a556cb88bceda82ee28502ebce9283`.
The independently tested 85 Python and YAML source and test files had combined
SHA-256 `79c4d10ea2f179ff0bd664b3378259f82b890dd5a38e463b1bb9e3d3ccdb6ea0`.
The fingerprint hashes each sorted relative path, a NUL separator, and its
binary SHA-256 digest.
Local execution used Conda `nn_window_decoding` on Linux WSL2 x86-64 on an
Intel Core i7-13700H, Python 3.11.18, PyTorch 2.7.0+cpu, PyG 2.6.1,
NumPy 2.2.6, SciPy 1.17.1, Stim 1.15.0, PyMatching 2.2.2, Hydra 1.3.2,
pytest 8.4.2, and pytest-xdist 3.8.0. Workers were limited to CPUs 0–7
and used one PyTorch intra-op and one inter-op thread. Integrated workflows
used `runtime=test_cpu`, with zero loader workers and inline sampling.

```bash
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
export BLIS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1 PYTHONHASHSEED=0
taskset -c 0-7 conda run --no-capture-output -n nn_window_decoding \
  python -m pytest -n 8 --dist=load --strict-markers --strict-config \
  tests/unit/test_p5_*.py tests/integration/test_p5_*.py
taskset -c 0-7 conda run --no-capture-output -n nn_window_decoding \
  python -m pytest -n 8 --dist=load --strict-markers --strict-config \
  -m 'not performance and not cluster' tests
taskset -c 0-7 conda run --no-capture-output -n nn_window_decoding \
  python exports/verification/P5/independent_probe.py
```

The focused run passed 41 checks. The final independent cumulative run passed
193 checks, including 152 inherited checks, with zero failures or skips.
Importing PyMatching exposed 104 Pyparsing deprecation warnings from the
installed Matplotlib font configuration. A separate two-row noiseless d=5
probe confirmed that the original global DEM returns a one-column all-zero
baseline prediction for an all-zero detector batch.

The independent probe ran the installed generation, training, paired
evaluation, and analysis commands in a scratch directory. It checked packed
decisions and identities, rowwise matching, Wilson and sparse interval bounds,
the exact tiny resampling distribution, and unresolved ratio behavior. It
rejected missing analysis choices, different checkpoint digests, and a
permutation whose ID file checksum had been recomputed. The ignored local
probe at the path above has SHA-256
`69989c25d1226d37339fbc0cbd898ec112b5e2dcb6bf841085c696da61d48981`.

regime and inference mode for continuation comparisons. The P6 campaign
